# Sample Prompts

## Instructions for writing new prompts (read first)

**One prompt = ONE scene (one moment, composition, and camera view).** Everything written is drawn into one picture, so two scenarios produce a split/collage image.

- One scenario only; don't merge ideas from several samples.
- One camera angle; don't describe the scene twice from different viewpoints.
- Each character described once: one pose, one outfit, no later restatements.
- No picture-within-a-picture (screens, photos, posters, mirrors, TV) showing another scene unless explicitly requested.
- Avoid "meanwhile", "then", "later", "before/after", "in another scene", "split screen", "panels", "collage", "multiple views", "sequence".
- One consistent background location.
- Samples show style only (wording, detail, tag format); don't copy a sample's structure if it spans multiple moments.
- Output a single prompt, not alternatives.

Reference style: a detailed natural-language description or a comma-separated tag list, often ending with a character name.
